## 作品名：High Score Shooting

# 概要

2Dシューティングアクションゲームです。
制限時間内に自機のショットを当て、ハイスコアを目指す作品で、短時間で繰り返し遊べることを意識して制作しました。

# 制作情報

* 制作期間：2026年2月〜2026年4月
* 開発人数：1人
* 担当範囲：企画、実装、デバッグ、UI作成

# 使用技術

* C++
* DirectX
* Visual Studio

# 工夫した点

* できる限りシンプルにし、ほとんどの操作をマウスのみでできるようにしました。
* 簡単になりすぎないように、敵の動作を乱数で管理しています。
* これまでのスコアを高い順に5つ保存し、リザルト時にランキング表示します。

# 起動方法

1. 実行ファイルフォルダーをエクスプローラーで開く
2. 「High Score Shooting.exe」を起動する

# 操作方法

* 移動：マウスカーソル
* 攻撃：左クリック
* 途中終了：Esc

※ 自機のショットが敵に当たると加点、敵のショットが自機に当たると減点します。
